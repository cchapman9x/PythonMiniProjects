# PythonMiniProjects

A collection of Python mini projects built to strengthen programming fundamentals and problem-solving skills through practical tools, simulations, and experiments. I'm building these projects independently, one at a time, as learn more about Python. Each project starts with a small, usable version. I may revisit it later to improve the code, add features, or build a graphical interface as my skills develop. The project bank below is a collection of ideas to choose from. It is not a required sequence or a list of completed work.

### Project Tracking
Each project has two checkboxes:
- Built: A working version is finished
- Uploaded: That version has been added to this repository

Change [ ] to [x] as each milestone is reached. All projects currently remain unchecked in this tracker.
